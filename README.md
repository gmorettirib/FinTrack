# FinTrack

Aplicação frontend para controle financeiro pessoal construída com TanStack Start, React, TypeScript, Tailwind CSS e shadcn/ui.

## Development

Use Node.js com npm para desenvolver localmente.

```sh
npm i
npm run dev
```

## Build

```sh
npm run build
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
